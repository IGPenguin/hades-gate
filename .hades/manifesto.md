# HADES GATE: IDEA-TO-EXECUTION FRAMEWORK

## Philosophy
- **Kindness & Connectivity:** Every line of code serves human understanding.
- **Efficiency:** Minimize the "Interface Gap." High-speed execution, low-latency feedback.
- **Proactive Loyalty:** Anticipate needs and suggest playtest-ready outcomes.

## Artifacts
- **styx.md:** The source of raw intent. Read this to understand the "Oath."
- **papyrus.md:** The structural blueprint for all proposals. 
- **prions.md:** The output. Generate 3 "infectious" proposals here to reshape the code.
- **hades.py:** The catalyst logic that bridges the gate.

## Codex
- **No Ghosting:** Always explain *why* a change is made.
- **Consent First:** No touching personal data, system files, or external APIs without explicit confirmation.
   - **Git history:** Open for reading.
   - **Personal notes:** Access only via whitelisted seeds in styx.md.
   - **Risk Detection:** If a task borders on these, halt and ask for consent.
- **State Preservation:** Before major refactors, the AI must suggest a `git tag` or snapshot.
- **Backlog Awareness:** When proposing Path B or C, cross-reference the `TODOs.md` (if present in the Arche). Favor implementations that resolve the current seed while simplifying or modularizing pending tasks in the backlog.
- **Anti-Hallucination:** If logic is fuzzy, halt and ask for "Intent Clarification."

## Execution
When "Igniting" seeds from styx.md, always produce 6 core Prions (The Hexalogy) plus one ultimate outcome:
1. **Option A - The Spark (Fastest path):** Minimal friction, immediate result.
2. **Option B - The Weave (Systems integration):** Leveraging infrastructure for unforeseen efficiency.
3. **Option C - The Sovereign Path (High polish):** High quality, clean architecture.
4. **Option D - The Echo (Standard patterns):** A common or proven existing solution.
5. **Option E - The Rift (Experimental):** Outside-the-box, novel, or highly efficient logic.
6. **Option F - The Chimera (Flashy hacks):** Flashy results with a pragmatic interior.

---
**The Synthesis (Refined convergence):** A curated selection of elements from the Hexalogy above, representing the most balanced or potent path forward.
